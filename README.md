# Innoventix Hub

Next.js site for [innoventixhub.tech](https://innoventixhub.tech). Audience: D2C brands and SMBs in the US, UK and EU.

## Scripts

- `pnpm dev` starts the local server
- `pnpm build` creates the production build
- `pnpm start` serves the production build

Coolify can use the included `Dockerfile` (`output: "standalone"`).

## Config

Contact details, the Calendly URL, the chatbot embed slot and the live-ads flag live in `src/config/site.ts`.
