# Innoventix Hub — Portfolio Site

Static single-page site. Dark charcoal theme, gold accents, Outfit font. Netlify-ready.

## Files
- `index.html` — page structure
- `styles.css` — theme + animations
- `script.js` — sliders, reveals, mobile nav
- `assets/logo/` — logo variants (blue & white; icon, horizontal, vertical)
- `assets/team/` — team photos
- `netlify.toml` — deploy config

## Deploy on Netlify (30 sec)
1. Zip this folder
2. Drop at https://app.netlify.com/drop
3. Live URL instantly

## Or via CLI
```
npm i -g netlify-cli
netlify deploy --prod --dir .
```
